# Site languages (EN / 中文 / ES)

Covers `index.html`, `projects.html` and `collaborators.html`. The blog has its own EN / 中文 setup (see `blog/AI-GUIDE.md`) and is not part of this.

## How it works

| URL | Language | Edit it? |
|---|---|---|
| `index.html`, `projects.html`, `collaborators.html` | English, and the **source** for all three languages | Yes |
| `zh/*.html` | 繁體中文 | No, generated |
| `es/*.html` | Español | No, generated |

Each language has its own URL so search engines index all three (`hreflang`, self canonical, translated `<title>`, description and social preview). The generated pages contain only their own language.

`i18n.js` handles the language switch (it moves between the URLs). First-time visitors always see English. If their region (IP lookup via ipapi.co, cached 30 days) or, failing that, their browser language suggests 中文 or Spanish, a small invitation at the bottom offers that version; closing it hides it for good. Once a reader picks a language (switch or invitation), the English URLs take them straight to it on later visits. Crawlers get neither redirects nor the invitation; the 中文 and Spanish URLs never redirect.

## After editing a page: run the build

```
python tools/build_i18n.py
```

Then commit the source page **and** the regenerated `zh/`, `es/` and `sitemap.xml`. Never edit `zh/` or `es/` by hand: the next build overwrites them.

## Writing translatable content (in the source page)

- Static text, one span per language:
  `<span data-lang="en">Projects</span><span data-lang="zh">專案</span><span data-lang="es">Proyectos</span>`
  For longer blocks, put `data-lang` on the `<p>` / `<div>` itself. Keep 中文 text on one source line (a line break inside 中文 shows up as a space).
- Text built in JavaScript: `SiteLang.t({ en: '…', zh: '…', es: '…' })`; dates: `SiteLang.date('2026-04-09', lang)`.
- Page title and meta: `data-zh="…" data-es="…"` on `<title>` and on the description / `og:` / `twitter:` meta tags.
- Links between the three pages are written normally (`projects.html`, `#talks`); the build points them at the same language.
- The build stops with an error if a page still has text in another language or an untranslated title/meta tag.

## Translation conventions

- 中文: Taiwan usage (資料, 影片, 專案), full-width punctuation, `SOS基金會`, `SOS 研究中心`; people with a Chinese name are shown with it (詹偉平 and the collaborators listed in `collaborators.html`, field `nameZh`).
- Español: neutral Spanish for Latin America and Spain, tuteo, masculine forms for Ping, sentence-case headings, `17 000` with a non-breaking space.
- Paper titles, journal names and citations stay in English in every language.
